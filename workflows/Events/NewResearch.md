---

**This workflow is not written.**

The file has existed empty since the repository was created. It is referenced in
code: `framework/workflows/events.py` defines `NEW_RESEARCH = "new-research"`, and
`workflows/README.md` states that every workflow defines a trigger, required inputs,
departments activated, deliverables, and completion criteria. None of those are
recorded here.

The content is deliberately not invented. Writing it is a governance act, and
governance documentation is frozen by ADR-002 until the mechanics layer can produce
evidence for the gates already specified. This marker exists so the gap is visible
rather than reading as an oversight.

See `docs/HANDOFF.md`.
